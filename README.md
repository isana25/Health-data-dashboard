# Global Health Data Explorer Dashboard

An interactive data visualization dashboard for exploring global health indicators with AI-powered insights.

## Features

- 📊 **Interactive Visualizations**: Time series, regional comparisons, and heatmaps using Plotly
- 🔍 **Smart Filtering**: Filter by country, region, indicator, and time period
- 💡 **Guided Insights**: AI-powered detection of trends, anomalies, and significant changes
- 🌍 **Real-World Data**: Based on World Bank Global Health Indicators
- 📱 **Responsive Design**: Works on desktop, tablet, and mobile devices
- ⚡ **Fast Deployment**: One-click deployment to Netlify

## Tech Stack

- **Frontend**: React 18
- **Visualization**: Plotly.js + react-plotly.js
- **Styling**: CSS3 with custom design system
- **Data Processing**: Lodash
- **Deployment**: Netlify
